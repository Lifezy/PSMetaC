# PSMetaC 0.2.0-alpha.6 更新说明

本版集中处理真实批量任务暴露出的状态、磁盘规划和界面可读性问题。程序、关于页、
Windows 文件版本、MCP 运行时和安装包文件名统一为 `0.2.0-alpha.6`。

## 任务与报告

- “检查后等我确认”会在预检完成后显示结论、证据、对象数量、源文件状态和下一步，
  然后等待“开始处理”或“仅保留检查结果”。“只检查并结束”继续作为独立方案。
- 直接保存任务未完成全部目标对象时使用“部分完成”，不再进入普通成功、全部通过或
  成功通知统计；旧任务按原因代码兼容归类。
- 失败、阻止、复核和部分完成优先显示普通中文结论；内部原因代码保留在技术详情。

## 多盘与批量容量

- 安全副本的工作副本、Photoshop 暂存成品和待复核结果使用用户选择的成品盘。
  软件数据目录只保存数据库、日志、报告和小型诊断资料。
- 创建批量任务前按实际卷汇总整批峰值预算，显示盘符、用途、所需、可用和缺口；
  任一卷不足时整批不创建，避免队列后段才逐个失败。
- 待复核结果在成品盘的 `.psmetac-review/<任务编号>` 中受控保存；人工接受、放弃、
  保留和自动清理均能识别该位置。
- 若复核转移仍失败，程序保留任务工作目录中的诊断副本并进入人工复核，不再为了清理
  工作区而删除最后可取得的长任务成果。

## 界面

- 亮暗主题统一使用语义化颜色、边界、文字、间距、圆角和控件状态；暗色输入框不再
  使用亮色硬编码背景。
- 修正复选框勾选对齐、说明图标拉伸、设置导航溢出、宽窗口内容失衡、禁用态不清楚、
  筛选条件长期平铺和长内容越界。
- 任务筛选默认收起，通过“筛选”按钮展开；任务详细方案放入右侧抽屉。
- 运行检测页面保持被动，进入页面不会连接或唤醒 Photoshop，只有点击“开始检测”后
  才执行连接测试并提前说明可能产生的影响。

## 发布边界

- 81 项不启动 Photoshop 的自动测试通过。
- 已验证打包后的 `win-unpacked` 应用和新安装器欢迎页；安装器验收只启动并截图后退出，
  没有执行安装、覆盖升级或卸载。
- 本轮构建没有读取生产 PSD/PSB，也没有启动 Photoshop。智能滤镜慢开、完整批量性能和
  Photoshop 端到端处理仍需使用隔离样本另行验证。
