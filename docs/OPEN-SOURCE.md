# 首次开源整理

本仓库从 `0.2.0-alpha.6` 当前源码导出，以干净的公开提交开始。原开发目录和本地研发
历史保留在维护者机器上，没有改写或上传。

## 公开范围

- 应用源代码、自动测试、合成任务模板、数字指标基线。
- 自包含 Photoshop 执行脚本、图标、当前安装器源资源和构建脚本。
- README、操作/架构/MCP/报告文档、贡献指南、MIT 许可证、问题模板与 Windows CI。

## 排除范围

- 生产 PSD/PSB、图片和工程素材。
- 运行数据库、真实配置、日志、诊断包、用户目录与历史截图。
- 开发机器的反馈记录、含真实路径的旧构建文档、旧安装包和 Electron 缓存。
- 原 Git 历史及其个人路径信息。

## 复现

`scripts/export-open-source.mjs` 按白名单导出到新的空目录；它拒绝覆盖已有内容。
`scripts/check-public-tree.mjs` 检查被 Git 跟踪的公开文件是否混入运行数据、个人路径、
大体积文件或常见令牌格式。该检查用于辅助审查，不构成对所有机密格式的证明。

当前仓库中的路径示例为通用测试目录。`vendor` 清单保持字节级哈希验证；Git 属性
保留执行脚本原始字节，避免换行转换使资源校验失效。

CI 在 Windows 上执行无 Photoshop 的测试与资源校验，手动触发时可生成未签名安装包。
实机安装/升级/卸载和 Photoshop 工作流仍需隔离样本验收，不能由 CI 代替。

导致允许目录误拒绝或排除目录漏判。现已将两侧路径解析到最近的真实父目录后比较，
并补充目录别名、尚未创建的输出路径和相邻目录边界回归。
