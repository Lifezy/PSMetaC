# 运行与故障处理

## 安装与 alpha 验证

当前安装程序是按用户安装，不需要 Windows 服务，也不会开放网络端口。建议
按以下顺序在每台测试电脑上验证：

1. 构建后核对安装程序的 SHA-256 与本次生成的 `dist/build-verification.json` 一致。
2. 因为 alpha 版本尚未代码签名，Windows 可能显示“未知发布者”。不要关闭
   SmartScreen 或防病毒功能；只在确认哈希后继续。
3. 首次启动时必须选择数据目录；允许输入/输出目录可稍后配置。排除目录默认
   为空，由用户自行管理。
4. 先用空队列确认窗口、托盘和 MCP 正常，再只提交专用测试目录内明确选择的副本。
5. 第一项文件任务使用 `inspect_only`。检查报告无解析警告后，再决定是否
   创建 `await_approval` 或 `auto_if_eligible` 任务。

“按用户安装”的优点是不用管理员权限、不会影响其他 Windows 用户；缺点是
每台电脑和每个账户都要单独安装。这个取舍符合首版“每台电脑独立运行”的
范围。

## 手动选择与无人值守路径

- 桌面文件选择器只授权精确选中的文件；拖入文件夹时会递归扫描，但只授权扫描到并
  留在待处理清单中的精确 PSD/PSB，不会永久授权整个文件夹。这些文件可以位于
  允许输入目录之外。
- 拖放扫描不跟随符号链接；Delete、右键菜单和垃圾桶只移除清单项，不删除磁盘文件。
- 手动指定的成品目录和明确选择的“源目录内 PSB_Cleaned”也只绑定当前任务。
- MCP 和收件目录属于无人值守入口，仍必须位于允许输入/输出目录中。
- 排除目录是可选的最高优先级规则；留空表示没有固定排除目录。

这种设计的优点是手动任务不必为了一个文件放开整个父目录；代价是 MCP 和
监控配置比手动任务多一步目录授权。桌面选择记录会进入任务账本和事件日志，
不会静默扩大全局允许目录。

## PSD 实验功能

在“设置 → 文件类型”中显式开启后，PSD 可用于：

- `inspect_only`：仅预检；
- `await_approval`：预检后等待桌面人工批准；
- `auto_if_eligible`：只有另行开启“PSD 无人值守”后才允许，并保留实验警告、路径保护、日志、报告和隔离规则。

PSD 尚未达到 PSB 的验证覆盖。开放无人值守便于用户在自有沙盒中积累多版本样本；
代价是 Photoshop 保存差异和验证失败率更不可预测，因此默认关闭，正式生产前仍需
检查单文件报告与人工复核结果。

## 从源代码构建

```powershell
pnpm install --frozen-lockfile
pnpm run verify:package
pnpm run test
pnpm run pack:win
pnpm run verify:dist -- --require-installer
```

`verify:dist` 会核对 ASAR 主入口、EXE 中记录的 ASAR 完整性哈希、四个已验证
Photoshop 执行资源以及安装程序 SHA-256，并在 `dist/build-verification.json`
留下机器可读证据。构建成功不等于已经安装，也不等于生产 PSB 已验收。

每次发布还必须保证 `package.json`、`src/version.ts`、安装包文件名、EXE 文件版本/
产品版本、ASAR、MCP、报告和更新说明中的版本号一致。任一处不一致都视为构建失败。
本版内容与尚未覆盖的验证见[更新说明](RELEASE-NOTES-0.2.0-alpha.6.md)。

## 结果处理

- **成功**：新副本进入指定目录或 `PSB_Cleaned`，报告跟随。
- **跳过**：没有启动 Photoshop，只生成报告。
- **阻止**：路径、版本、解析或空间不安全；修复原因后新建任务。
- **隔离**：副本存在，但不能交付。先看像素、结构和智能对象失败项。
- **取消**：临时输出不发布；日志和报告保留。
- **严重暂停**：检查对应任务报告后，只能在桌面界面确认解除。
- **直存完成（未校对）**：源文件已覆盖；先确认报告中的备份路径，再决定是否保留备份。

## 批处理暂停和终止

- 点击“完成当前项后暂停”时，当前正在处理的文件会先完成全部安全收尾，然后队列
  停止领取新文件。暂停后可以点击“继续处理任务”恢复。
- 点击“完成当前项后终止”时，当前文件同样会先完成；所有尚未开始的任务会生成取消
  结果，不会在之后自动继续。
- 大文件正在保存时，暂停或终止可能需要较长时间才生效。这不是卡死，而是在避免
  强行关闭 Photoshop 或留下半保存文件。
- 直存模式进入保存后不可回滚；此时到达的取消、暂停或终止会等待保存结束。
- 直存模式遇到部分智能对象失败时会保存此前已完成的清理，并明确标记“部分完成、
  未校对”；如果这些部分结果也不能接受，应从备份恢复或由人工决定下一步。

## Photoshop 使用规则

- 有任何用户文档时，任务保持 `waiting_photoshop`。
- 工具可以通过 COM 正常启动 Photoshop。
- 工具从不强制结束 Photoshop。
- 正在保存时请求取消，保存动作可能先完成；结果仍不会发布。
- 直存模式是例外：保存完成的就是源文件本身，报告会标记“未校对”，不会把它描述为
  经过严格验证的成品。
- Photoshop 模式默认不额外关闭并重新打开大型文件；“保存后能重新打开”和“保存与
  重开画面一致”是可选严格检查。未来免 PS 二进制 XMP 模式应重新把打开性检查作为
  重点，因为它不借助 Photoshop 自己的保存器。

## 磁盘

安全副本把工作、暂存与复核文件放在成品所在卷，默认按源文件体积的 3 倍加 10 GiB
检查一次容量。整批任务按卷汇总并计入队列前段结果占用；开始执行前再次检查。
这个门槛是“是否开始”的安全判断，不会自动删除其他文件腾空间，也不包含 Photoshop
独立配置的暂存盘需求。

直存模式不创建工作副本和另存成品，因此按“源文件保存余量 1.2 倍 + 可选备份 +
固定安全保留量”分别检查源文件所在磁盘和数据目录。它通常比安全副本需要的空间
少，但不能换来保存后校对能力。

待复核结果位于成品目录的 `.psmetac-review/<jobId>`；旧版数据目录隔离区仍可管理。

## 保留策略

- `temporary_only`：默认。删除工作副本和大型预览，保留成品、隔离和报告。
- `quarantine_30d`：在默认行为上，把超过 30 天的隔离任务目录移入回收站。
- `manual`：工作副本也保留，由用户处理。

任何策略都不会自动删除成功成品和报告。

## 多电脑

每台电脑独立数据目录和队列。设置导出文件只包含安全设置和收件目录，不
包含机器编号、数据库、命名管道令牌或任务历史。

## 第一轮真实验收

1. 在独立测试目录内准备专用测试副本。
2. 确认源文件不在 Photoshop 中打开。
3. 先提交 `inspect_only`，查看解析警告和预计 XMP。
4. 再创建 `await_approval` 任务。
5. 确认输出、隔离和数据根目录空间足够。
6. 运行后检查报告、源 SHA-256、像素和智能对象失败项。
7. 在至少几类合成文件通过前，不把程序用于生产原件。
